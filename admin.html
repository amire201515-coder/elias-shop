مدیریت فروشگاه

ورود مدیر

این صفحه برای صاحب فروشگاهه. بدون «توکن»، هیچ‌کس نمی‌تونه چیزی تغییر بده. توکن فقط روی همین مرورگر ذخیره می‌شه و برای هیچ‌جا غیر از گیتهاب فرستاده نمی‌شه. توکن رو برای هیچ‌کس نفرست و توی گفتگو با هوش مصنوعی هم ننویس.
توکن رو چطور بسازم؟
  1. توی مرورگر، وارد گیتهاب شو و برو به github.com/settings/personal-access-tokens/new
  2. اسم: elias-shop-admin. انقضا: ۹۰ روز یا بیشتر.
  3. Repository access: Only select repositories و بعد elias-shop رو انتخاب کن.
  4. Permissions ← Repository permissions ← Contents: Read and write.
  5. پایین صفحه Generate token رو بزن، توکن رو کپی کن و اینجا پیست کن.
